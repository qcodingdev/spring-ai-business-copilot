# 模块规划

| 模块 | 2.4.0 纵向升级重点 | 继续保持的硬边界 |
|---|---|---|
| Data | 检测卡住的交接领取和过期结果清理积压，路由到既有记录/交接页面 | 只读、SQL 两次校验、人工确认 |
| Knowledge | 过期/冲突/索引失败或超时资料不进入检索；展示来源问题并受控重试 | 无证据拒答、ACL 与生命周期失败关闭 |
| Support | 检测未知/卡住回写和 SLA 违约，路由到人工复核与恢复 | 不自动外发、退款或改账号 |
| Report | 检测卡住调度、失败运行和逾期复核草稿 | 不自动发布 |
| HR | 检测逾期评估复核和入职必办任务 | 不评分、排名、筛退或写 ATS |

就绪聚合属于应用交付面，只读取五个模块已经持久化的安全状态，不把模块 Repository
上移到 `platform`。只有至少两个模块真实复用的底层能力才进入 `platform`。
