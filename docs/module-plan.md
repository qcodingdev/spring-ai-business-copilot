# 模块规划

| 模块 | 2.3.0 纵向升级重点 | 继续保持的硬边界 |
|---|---|---|
| Data | 查询、治理、记录、交接的受控 UI | 只读、SQL 两次校验、人工确认 |
| Knowledge | 问答、文档、来源、质量复核 UI | 无证据拒答、ACL 失败关闭 |
| Support | 工单、复核、连接、SLA 和内部备注回写 UI | 不自动外发、退款或改账号 |
| Report | 生成、记录、来源、调度和导出 UI | 不自动发布 |
| HR | 招聘协同、授权、面试、ATS、员工问答、入职 UI | 不评分、排名、筛退或写 ATS |

只有至少两个模块真实复用的能力才进入 `platform`。2.3.0 的共享新增能力仅包括
显式请求语言传播和由多个外部适配器使用的网络安全客户端。
