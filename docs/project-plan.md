# 项目规划

当前主线是五个既有业务闭环的可信、可诊断、可评测和可交付升级，不增加第六个
Copilot。

- 2.2.x：企业 API、质量闭环和交付硬化基线。
- 2.3.0：Vue 双语业务工作台、企业能力受控 UI、显式 AI 输出语言、外部连接安全。
- 2.3.1：修复 Notion 完整内容同步，固定云知识源和客服系统 HTTP 契约，增加周期性
  漏洞扫描与受控依赖维护；依赖升级不自动创建远端分支。
- 2.4.0：增加五模块企业运行就绪检查、保留期内禁止改写的追加式证据快照和整改路由；知识检索对过期、
  冲突资料统一失败关闭，形成“检查 → 整改 → 复查 → 留证”的运营闭环。
- 后续：根据真实使用证据纵向补齐五模块模型评测、性能和供应商沙箱验证，不提前拆分
  微服务、建设多租户 IAM、模型平台或工作流平台。

`2.4.0` 基于正式 `v2.3.1` 开发，不增加业务模块。正式发布使用同一
提交上的主干、`v2.4.0` 长期版本分支、不可变标签和 Release。后续版本只基于真实故障、
评测和供应商沙箱证据纵向加固，不增加第六个 Copilot，也不把部署方 IAM、密钥管理或
供应商认证包装为项目内置能力。
