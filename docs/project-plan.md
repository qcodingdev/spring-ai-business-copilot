# 项目规划

当前主线是五个既有业务闭环的可信、可诊断、可评测和可交付升级，不增加第六个
Copilot。

- 2.2.x：企业 API、质量闭环和交付硬化基线。
- 2.3.0：Vue 双语业务工作台、企业能力受控 UI、显式 AI 输出语言、外部连接安全。
- 2.3.1：修复 Notion 完整内容同步，固定云知识源和客服系统 HTTP 契约，增加周期性
  漏洞扫描与受控依赖维护；依赖升级不自动创建远端分支。
- 后续：根据真实使用证据纵向补齐五模块评测、性能和供应商沙箱验证，不提前拆分
  微服务、建设多租户 IAM、模型平台或工作流平台。

`2.3.1` 是基于正式 `v2.3.0` 的兼容维护版本，不增加数据库迁移和业务模块。正式发布
仍使用同一提交上的主干、`v2.3.1` 长期版本分支、不可变标签和 Release。后续版本只基于
真实故障、评测和供应商沙箱证据纵向加固，不增加第六个 Copilot，也不把部署方 IAM、
密钥管理或供应商认证包装为项目内置能力。
