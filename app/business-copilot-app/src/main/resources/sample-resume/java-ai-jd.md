# Java AI 应用开发工程师（虚构岗位）

## 岗位目标

负责把大模型能力接入企业知识、客服、招聘、数据分析和报告场景，交付可追溯、可复核、可运行的 Java AI 应用。

## 工作职责

- 使用 Java 21、Spring Boot 和 Spring AI 开发企业 AI 应用。
- 建设基于企业资料回答的知识检索、引用校验和无依据拒答能力。
- 对接 PostgreSQL、pgvector 和只读业务数据源。
- 建立输入输出安全检查、人工复核、审计和基础可观测性。
- 与产品、运营和业务负责人共同完成需求澄清、上线和问题复盘。

## 必须条件

- 三年以上 Java 与 Spring Boot 项目经验。
- 理解 REST API、关系型数据库、事务和常用测试方法。
- 有 RAG、向量检索或大模型应用的实际项目经验。
- 能解释模型输出的证据边界，不把 AI 建议当作自动业务决定。

## 加分条件

- 熟悉 Spring AI、pgvector、Testcontainers 或 Railway。
- 有企业知识库、客服、HR 或数据分析项目交付经验。
- 有 AI 效果评测、安全治理或成本监控经验。
