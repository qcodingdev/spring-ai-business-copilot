# Java 后端工程师（虚构职位）

## 工作内容

- 负责订单、客户和支付相关的 Spring Boot 服务开发。
- 设计并维护 REST API、PostgreSQL 数据模型和自动化测试。
- 与产品、测试和交付团队协作完成版本发布。

## 必选要求

- 3 年以上 Java 后端开发经验。
- 有 Spring Boot 构建 REST API 的实际项目经验。
- 熟悉 PostgreSQL 或其他关系型数据库。
- 能编写单元测试和集成测试。

## 加分项

- 有 Docker 容器化和 CI/CD 实践。
- 有 Spring AI 或其他生成式 AI 应用开发经验。

本职位描述仅用于项目演示，不对应真实招聘岗位。
